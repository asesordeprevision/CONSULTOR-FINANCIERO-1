# Estudio: curso "Seguridad de la Información" (Universidad Consupago)

Iniciado 2026-11-19. Se completa con lo que comparta el usuario.

## Conceptos básicos (ejercicio de relacionar)

| Concepto | Definición |
|---|---|
| **Activo** | Todo lo que tiene valor para la organización. Puede ser físico (equipos, documentos) o lógico (software, bases de datos, información). |
| **Amenaza** | Todo lo que puede causar daño. Viene de fuera (hackers, virus) o de dentro (errores humanos, mal uso). |
| **Vulnerabilidad** | "La puerta abierta": una debilidad que una amenaza puede aprovechar para causar daño. |
| **Ataque** | La acción que causa el daño: el intento intencional de una amenaza de aprovechar una vulnerabilidad para afectar un activo (robar, alterar o destruir información, o interrumpir servicios). |
| **Impacto** | La consecuencia del ataque: mide qué tan grave sería el daño si ocurre un incidente. |
| **Riesgo** | La combinación de posibilidad y daño: probabilidad de que ocurra un ataque × el impacto que tendría. |

Cadena para recordar: una **amenaza** aprovecha una **vulnerabilidad** con un **ataque** contra un **activo** y causa un **impacto**. El **riesgo** es la probabilidad multiplicada por el impacto.

Ejemplo en la operación: la INE y los recibos de nómina del cliente son el activo. El phishing es la amenaza. Un celular sin bloqueo o un WhatsApp personal es la vulnerabilidad. El ataque sería el robo del expediente, y el impacto, una suplantación de identidad para sacar un crédito.

## Escenarios (¿qué harías?)
1. Correo "Detectamos actividad inusual. Haz clic aquí para verificar tu cuenta" → **Lo ignoras y lo reportas al Área de Seguridad**. Es phishing: genera urgencia y lleva a un enlace para robar credenciales.

## Examen final Seguridad de la Información
1. ¿Qué es la seguridad de la información? → **b. El conjunto de procesos y metodologías diseñadas para proteger los datos confidenciales, privados o sensibles de una organización** (no solo herramientas tecnológicas ni solo lo digital).
2. ¿Quién es el Oficial en Jefe de Seguridad de la Información? → **c. CISO** (Chief Information Security Officer). El BISO (Business Information Security Officer) es el enlace de seguridad dentro de cada área de negocio.
3. ¿Qué es un activo de información? → **b. Toda la información en formato físico o digital** (los medios donde se guarda o procesa, opción c, son activos de soporte o tecnológicos; la opción a describe el ciclo de vida). Respuesta razonada, con ambigüedad entre b y c.
4. Ejemplo de amenaza lógica → **c. Programas con virus o contraseñas débiles**. Robos o desastres naturales son amenazas físicas; el personal interno es una amenaza humana.
5. ¿Cuándo se produce un ataque? → **c. Cuando una amenaza aprovecha una vulnerabilidad**.
6. Proteger la información es vital para la continuidad y los objetivos del negocio → **Verdadero**.
7. ¿El ciclo de vida de la información concluye cuando deja de ser útil? → **Falso**. Concluye con su destrucción o eliminación segura, después de cumplir los plazos de conservación. Fases: creación, almacenamiento, uso, transmisión, archivo y destrucción. Respuesta razonada: si la marcan mal, cambiar a Verdadero.
8. Información que solo puede ser accedida por un grupo muy limitado → **a. Información restringida**. Clasificación usual, de menor a mayor: pública, interna (uso interno), confidencial (áreas o personas autorizadas) y restringida (grupo muy limitado). Si la marcan mal: confidencial.
